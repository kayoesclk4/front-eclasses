# E-Classes Front

Front-end do sistema E-Classes.

## Como executar

1. Inicie a API na pasta `eclasses_api`:
   `npm install`
   `npm start`
2. Abra o `index.html` com o Live Server do VS Code.
3. O front consome a API em `http://localhost:3000/api/`.

## Operações

O front possui listagem, cadastro (POST), edição (PUT) e exclusão (DELETE) para jogos, times, competidores e confrontos.
